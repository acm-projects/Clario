# Shopping cart repository

- `main.py`: public checkout entry point, `order_total(items, discount_percent=0)`.
- `cart.py`: subtotal and checkout orchestration.
- `discounts.py`: percentage discount helper.
- `test_checkout.py`: editable visible regression tests, executed by Run Tests.

Open the Incident brief for the task and behavioral contract. Submit also runs
server-managed edge-case tests. No external packages are required.
